## What happened

OpenAI's help article for ChatGPT agent now opens with: "ChatGPT agent is no longer available. Use ChatGPT Work for longer, multi-step tasks and finished deliverables. For supported browser workflows, see Using cloud browser in ChatGPT" ([OpenAI Help Center](https://help.openai.com/en/articles/11752874-chatgpt-agent)). The rest of that article, including the old limits of 40 agent messages a month on Plus and 400 on Pro, is still there but describes a product you can no longer use.

OpenAI has not published a dated retirement notice for agent mode, so we can't give you an exact switch-off date. On OpenAI's community forum, an OpenAI support account wrote that it was "sorry that the Agent-to-Work transition wasn't communicated clearly" and that the help center was being updated to say agent is no longer available ([OpenAI Developer Community](https://community.openai.com/t/agent-mode-menu-disappeared-after-recent-performance-issues-plus-plan/1386007/66)).

**What replaced it.** ChatGPT Work arrived in OpenAI's release notes in the July 13, 2026 entry, described as "an agent for longer, more involved tasks." It can research and analyze, work across connected apps and files, and create documents, spreadsheets, presentations, reports and Sites, while you follow progress and approve important actions. It also runs scheduled tasks that repeat or trigger on changes ([ChatGPT release notes](https://help.openai.com/en/articles/6825453-chatgpt-release-notes)). On August 27, Work's cloud browser gained the ability to finish tasks on websites you sign in to, asking for confirmation before things like payments or bookings; that sign-in feature is on Plus and Pro ([release notes](https://help.openai.com/en/articles/6825453-chatgpt-release-notes)). Plus and Pro can also trigger Work tasks from new Gmail messages, Slack messages or GitHub pull request activity ([release notes](https://help.openai.com/en/articles/6825453-chatgpt-release-notes)).

**Who gets it and what it costs.** On web and mobile, Work rolled out to paid plans except Free and Go ([release notes](https://help.openai.com/en/articles/6825453-chatgpt-release-notes)). There is no separate price: Work "follows the same usage structure as Codex," drawing on your plan's included allowance, with credits for extra usage ([OpenAI Help Center](https://help.openai.com/en/articles/20001275-chatgpt-work-and-codex)). Pro now comes in $100, $200 and $500 a month tiers ([release notes](https://help.openai.com/en/articles/6825453-chatgpt-release-notes)).

**Atlas is gone too.** OpenAI's Atlas launch post is now headed "Atlas has since been deprecated" ([OpenAI](https://openai.com/index/introducing-chatgpt-atlas/)). The release notes say OpenAI is "bringing browser-based agentic capabilities into ChatGPT and Codex" and that Atlas was scheduled to stop working on August 9, 2026; bookmarks, tabs and history did not transfer automatically ([release notes](https://help.openai.com/en/articles/6825453-chatgpt-release-notes), [OpenAI Help Center](https://help.openai.com/en/articles/20001371-evolving-atlas-into-chatgpt-for-browser-based-agentic-work)). OpenAI now points browser work to the new ChatGPT desktop app and its Chrome extension.

## Our take

This is a rename plus an upgrade, handled badly. Work does more than agent mode did: it produces finished files, runs on schedules and triggers, and on desktop can use your local files and apps. But people found out because a menu item or a scheduled task disappeared, not from a notice. If you build routines on top of a vendor's agent, that's the lesson: features get folded and renamed with little warning.

**For businesses:** if you had workflows or staff guides built on "agent mode" or Atlas, rewrite them for Work now, and check that Work is switched on for your workspace. On Enterprise and Edu it is controlled by admins. Re-test anything that logs in to websites or sends things on your behalf; the confirmation steps have changed.

**For everyday users:** if you pay for Plus, you haven't lost anything. Open the Work tab and give it the job you used to give agent mode. If you're on Free or Go, Work isn't on web or mobile for you. If you mainly used agent mode to click around websites, Manus, Claude or Grok Bot are worth a look; our [ChatGPT agent alternatives guide](/chatgpt-agent-alternatives/) compares them. Still have Atlas installed? Save any bookmarks you need and uninstall it.
